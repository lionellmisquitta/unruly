# UNRULY drawing workspace WB1
MIT. No install, server account, runtime packages or CDN. Serve these files under /unruly/ on HTTPS (localhost also works). Modules and offline caching require a web origin; opening index.html as file:// is not the delivery route.

Combined batch: size/opacity/hex/HSL/swatches/preview, plain/dotted/grid/ruled/textured paper, vector layers, original Ink/Pencil/Marker/Airbrush, whole/partial/intersection erasers, JSON import/export. Eight Canvas2D/sRGB layer modes and protective layer locks. Stored in unruly-workspace-v3; copies legacy unruly-workspace (IndexedDB v1) and unruly-foundation without modifying either. Old versions keep separate copies. Quota/conflicts require export/reopen; never clear site data to update. Undo session-only,100 states and16MiB serialized history cap. No Drive/AI/smudge/watercolour/clipping/raster/proprietary brushes yet.

Five fixed drawing surfaces; brush samples and 80×48 layer thumbnails reuse scratch surfaces (none allocated per stroke/layer). Main backing dimension4096/DPR2 caps. Brush resampling20000 dabs, geometry20000 partial samples/200000 comparisons, errors cancel/retain board. Real device handwriting/pressure is not certified by synthetic tests. Candidate-only until independent QA and Gatekeeper review.

## Vector selection checkpoint C06-S1
Lasso with a pen or mouse on the active visible, unlocked layer. Select whole strokes, then choose Move and drag inside the dashed box. Copy, Cut, Paste and Delete selection each use the in-app clipboard; paste centres the copied strokes in the current view. Ctrl/Cmd+C, X, V and Delete work outside text fields. Every move, cut, paste or delete is one undo step. Escape cancels an active gesture. Clipboard and selection are page-session only; exports use v3 layer blend fields; v1/v2 imports migrate with fresh imported identities. Selection is cleared after board/layer changes or undo. Fingers continue to navigate. Rotation, scaling and individual vector-point editing remain later C06 work.

## U1 compact controls / v3 layers

The locked workspace uses compact original SVG icons and dark toolbar controls. Gallery, Actions, Lasso and the functional stroke Move action are upper left; Brush, Eraser, Layers and Colour are upper right. Size/Opacity and Undo/Redo remain in an independently collapsible left overlay. Every overlay preserves the full stage bounds and coordinate origin. U1 retains functional original brush/HSL controls; the richer brush library/colour disc belongs to U2. No Smudge or unimplemented Transform is presented.

Layer rows are topmost first, a minimum of 56 CSS pixels high and expanding with larger text, with 80×48 thumbnails, stable layer IDs, visibility, blend access and a menu. Selected opacity/blend controls appear once. Grip reorder starts after 6 CSS pixels; holding a row for 350 ms enables the same reorder. These are testable prototype thresholds, not claimed native timing. DOM reordering remains transient until pointerup; final bottom-first index is one model command. Escape, blur, lost capture and pointercancel restore the original stack without history. Edge autoscroll is bounded to the layer list and 12 CSS pixels per pointermove. Swipe left at least 48 CSS pixels with under 24 vertical pixels opens row actions; menu, keyboard Up/Down and explicit buttons provide alternatives. Locks block paint/erase/move/delete/opacity/blend while rename, visibility, stack reorder and unlocked duplication remain available.

Layer opacity previews through requestAnimationFrame and commits one command on change; cancelled previews restore the original board. No-op changes add no Undo. Thumbnails refresh after document commits/board switches, never during penmove; a maximum of 32 retained 80×48 images represents 491,520 nominal RGBA bytes, below 512 KiB. Opening/closing panels and outside dismissal cannot mark the artwork; dismissal consumes its pointerdown. Live drawing/busy transitions block panel mutations. Saved-update activation is preserved, and service-worker cleanup is limited to its own `unruly-workspace-u1-normal-` cache family; recovery caches and document stores are untouched.

Compatibility selectors: `#canvas`, `#save`, `#layer-list`, `[data-layer-id]`, `#add-layer`, `#layers-toggle`, `#modifiers-toggle`, `#layer-opacity`, `#layer-blend`; existing brush, colour, paper, selection, history, save/import/export and gallery IDs remain. `#panels` is an Actions-menu alias for Layers. Browser/device quality and checkpoint closure require independent QA.
