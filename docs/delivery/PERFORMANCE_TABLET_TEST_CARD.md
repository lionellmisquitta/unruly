2. Repeat on a populated board with the active layer on top; pan/zoom, then continue writing. Undo/redo and save/reload should preserve the drawing.
3. Draw on a lower layer with another visible layer above. Colours and transparency should stay correct; that case still uses the full renderer in P01 and may feel slower.
