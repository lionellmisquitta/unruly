# PEN1 device review

Open the cumulative UNRULY preview and use its safe Update button if offered. Tap Brush to open the library. Each of Pencil, Pen, Marker and Airbrush now contains five choices (20 total).

For obvious width variation, start with Flex nib, size20–40, Pressure changes width on, minimum width8%, Balanced response. Draw lightly then firmly. Soft widens early; Firm requires more pressure. Pressure changes opacity is optional and independent. Each stroke saves its own dynamics, so later control changes do not change saved ink. Mouse input uses the selected full width.

Expand Pen buttons & diagnostics. Default reported barrel button is Lasso; eraser signal is Eraser. Each can map to Lasso, Eraser, Pan or None. Hold the side button and draw around ink; hold again inside the selection and drag to move it. Manual Lasso also enables Move on pen hover inside the selected bounds and returns to Lasso outside. Temporary mappings restore the prior tool after release or cancellation.

The diagnostics show pressure range and button bits reported by this browser. Light/firm range variation confirms that varying pressure reached this page. Constant pressure (often0.5) or Mouse input cannot establish hardware support. OS/Bluetooth shortcut buttons that never reach the page cannot be mapped by the page. Surface, Lenovo and Xiaomi physical pen feel remain unverified until tested on the actual device.

Two/three-finger Undo/Redo retain the accepted U3 behavior; the browser context menu is suppressed on the drawing surface.

Export boards with new brush IDs/dynamics before reverting to an older preview, which can reject new IDs or ignore newer dynamics. Accepted U3 rollback remains available.
