## Engineering implications

- Text must remain an explicit object type with editable content, geometry, font identity and style. Export/rasterization needs a deliberate conversion; changing text-box dimensions must not silently change font size. Imported fonts require size limits, supported formats, availability after reload and an explicit fallback when missing. Platform fonts are not automatically part of UNRULY’s MIT distribution.
- Timelapse is an operation/time recording and replay contract. Animation Assist is layer/group frames; teaching movement traces are selected-object motion. These are three different models, history behaviors and exports. Neither animation nor screen recording can silently substitute for the requested timelapse.
- Infinite workspace, finite export rectangle, pixel dimensions and print DPI must remain separate. Pixel resampling changes artwork; DPI metadata alone does not add pixels or device-memory capacity. Page Assist does not make every layer a document page in our app.
- Reading the 3D chapters closes reference coverage, not scope. Model gesture bindings must not leak into the flat whiteboard interaction controller. No 3D parser, material, mesh or model export is required by the current whiteboard release.
- First-release text, reference images, finite canvas/export controls and timelapse remain named roadmap requirements. Frame animation, multi-page PDF editing and 3D are reviewed extensions outside the immediate U1/U2/U3 batch.
