# Morning tablet test — workspace and vector selection

Open https://lionellmisquitta.github.io/unruly/ while online. If “Reload to update” appears, finish drawing and tap it. Selection version shows a Lasso button and “0 selected”. Export a board JSON before testing existing work.

1. Choose dotted or textured paper. Change brush, colour, size and opacity; draw light and firm pen strokes. Add a layer, hide/show it, adjust its opacity and lock/unlock it. Try the three eraser modes and Undo.
2. Choose Lasso; draw a closed loop around two strokes. A dashed box should appear. Choose Move and drag inside it. Undo and Redo should each restore the whole move. Copy, New, then Paste: copied strokes should appear in the centre of the view. Cut/Delete selection should each undo in one step.
3. Confirm fingers pan/zoom without drawing or selecting. Reload only after “Saved on this device”: paper, layers and strokes should survive. Selection and clipboard intentionally reset on reload. After offline setup completes, briefly test opening and editing without a network connection.

Send pointed feedback on pen lag, pressure, palm interference, unexpected erasing/selection, and awkward controls. Actual Xiaomi pen/Surface pressure and drawing feel are not certified by automated Chromium tests. Advanced raster brushes, smudge, masks, blending, gap fill and AI remain later checkpoints.
