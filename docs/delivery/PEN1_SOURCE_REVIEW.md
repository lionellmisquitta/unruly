# PEN1 independent source and security review

Initial verdict: **READY_FOR_CI1**. No open blocking static finding. This is source review and permission for bounded QA execution, not checkpoint acceptance or publication authorization.

Reviewed the implemented `pen-input.js`, app gesture arbitration and diagnostic controls, model validation, preset catalogue, renderer, U2 catalogue UI, HTML/CSS, service-worker update list and QA workflow. The existing layer/document/history/renderer limits remain in force. New code uses pure pressure/button contracts, strict dynamics allowlists and numeric bounds, local configuration and per-stroke cloned snapshots. Dynamics are retained by import, clone, clipboard, transforms, partial-eraser fragments and history through existing copy/spread boundaries. Absent metadata selects the previous pressure formula; original airbrush gradient arithmetic has identical JavaScript values (`.25*.4 === .1`, `.45/1.5 === .30`). All twelve original preset descriptors remain unchanged.

Mapped operations store prior tool and automatic-Move state, freeze the operation during contact, and restore on end/cancel/blur/lost capture. Eraser admission failures call central cancellation and restore that ownership. Release pressure zero is replaced with the last valid stroke pressure at the final endpoint; in-contact tip zero is sampled in diagnostics, while pointerup/cancel zero is excluded. Automatic Move is admitted inside selection bounds and outside hover returns to Lasso. Context-menu prevention is limited to canvas and selection overlay, leaving unrelated document controls alone.

No new external request, device identity collection, secret, authentication or dependency boundary is introduced. The new file is included in offline precache. Configuration choices are allowlisted and stored locally. Diagnostics use textContent; no new HTML interpolation is added. Existing atomic model validation and transactional storage are the data trust boundary. Renderer work and backing-store budgets are unchanged.

Initial review refinements were made by the Builder before CI: legitimate contact-zero diagnostics, clearer constant-pressure wording, central eraser-error cancellation restoring prior tool, cursor reset and removal of an unused import. No application source was edited by this reviewer.
