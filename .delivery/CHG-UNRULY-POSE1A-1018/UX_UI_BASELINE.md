# Locked POSE1A interaction and visual baseline
Apply UX Architect and UI Design Director roles within this session; same-session review only. User intent already specified; no new discovery needed.
Actions → Pose references opens a modal with a large interactive rig preview and a compact controls pane. Pose/Proportions/Camera and Library sections use explicit headings/disclosures; focus remains in native dialog, Escape/Cancel discards draft. Drag joint for fixed-length pose edits; use selected joint numeric rotation controls for keyboard/depth/roll. Camera orbit uses drag on blank preview and equivalent numeric controls; full vertical orbit allowed. Proportions symmetric by default; profiles reusable across poses. Save pose, proportions or combined preset explicitly; Update requires selected saved record; imported records use fresh IDs and no overwrite. Save library and Apply reference are distinct; Cancel discards unsaved draft but not explicit library writes.
Apply reference places locked, translucent projected rig over document center; placement offset/scale/2D rotation/opacity available in studio. Reopen adjusts same per-board placement; hide/remove only reference. Local sidecar library and placements have separate portable backup/import, visible error/retry behavior and compare-before-write. Native artwork backups exclude these; help states it. Modal blocks artwork edits; overlay outside editor is pointer-transparent. Pose edits have local Undo/Redo, independent of artwork history. Pins apply to hands/feet and reject unsolvable edits visibly.
Visual direction inherits existing dark compact drawing workspace tokens, system typography, 44px controls, amber focus, blue rig/selected joint contrast. Desktop two-pane studio; phone preview first then controls with modal scroll, no horizontal overflow. No app-shell redesign. Orthographic default; perspective strength optional. Neutral floor and segment depth shading improve orientation, head/chest/pelvis guides remain simple.
States: ready/draft, unsaved edits, selected joint, pinned endpoint, invalid edit with unchanged draft, corrupt storage read-only, cross-tab conflict requiring reopen, saved and reference applied. Reference excluded from artwork/video exports. No external network/runtime packages.
