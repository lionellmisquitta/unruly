# EXPORT1 UX baseline

Single existing-workspace modal launched by Actions → Export artwork. Target/frame, device-local named-frame management and output settings are sibling sections. Known bounds/view/selection derive from host; manual rectangles and px/inches/DPI/aspect helper complete output intent. Configure → rendering/progress → explicit download; cancellation/error preserve artwork and permit retry. Corrupt/quota/cross-tab frame writes fail visibly; backup/import separate from native artwork. Native modal supplies focus containment/inert workspace; Escape cancels or closes. Existing component styling reused. Scope/constraints/risks in CONTRACT.md. Focused phone/offline/keyboard/cancel/preservation checks passed on db2611e7. No independent human/device acceptance inferred.
