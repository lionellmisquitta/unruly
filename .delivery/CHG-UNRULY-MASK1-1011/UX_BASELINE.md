# MASK1 interaction baseline

User authorized the next standalone layer masks build. Existing Layers menu → Add/Edit mask → canvas Hide/Reveal, with44px controls and persistent Editing mask + layer name. Edit artwork exits target; changing active layer or reload clears view-state target. Pen/mouse paint masks; finger navigates/picks colour and is rejected as palm during active pen. Eraser mapping reveals; smudge requires Edit artwork. Existing size0–100 and pressure profile drive mask brush; vector mode uses round mask tip, soft pixel mode uses soft mask tip. No shape recognition on mask strokes. Escape/pointer cancellation discards the entire gesture; completed gesture is one Undo. Mask menu disables/enables, inverts, resets to reveal all, removes undoably. Original art remains editable under disabled mask. Locks/visibility protect changes; disabled mask Edit re-enables explicitly through command history.
