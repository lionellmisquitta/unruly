# TIME1 constraints
No native board version change; model/history/storage/renderers remain byte-identical. Observation runs only after committed h.board replacements. Recording database unruly-timelapse-v1 is separate from artwork unruly-workspace-v3. Events preserve complete validated native board states using prefix/suffix text deltas; no evaluation of arbitrary patch paths. Every imported/persisted event is validated and reconstructed before replay. Malformed/corrupt histories are preserved and rejected, never repaired silently.

2,000states/32MiB UTF-8 event payload per board;128MiB global payload. IndexedDB overhead, UTF-16 JS memory and artwork/history memory are additional, not claimed inside renderer80MiB. Queue<=4snapshots/32MiB conservative UTF-16 sizing. Backpressure/quota/conflict stops capture visibly, no silent trim. At most8MiB native board per reconstructed state, existing32layers. Imported backup file<=32MiB+4096header allowance. Large delta/reconstruction CPU and storage latency require physical device/long-session acceptance; live input never captured per point but commit work still adds main-thread cost.

CAS metadata/append/budget commit atomically. Tombstones retain increasing revisions after discard, preventing stale-tab ABA append. Saved log and artwork autosave are independent transactions: a recorder state can persist before artwork autosave, and a failed recording write must not block drawing. Reload always pauses. Switching boards flushes capture and pauses. Resume appends an explicit gap/current-state marker; unrecorded edits are not fabricated. Actual elapsed time while paused is not included. Views are captured at committed changes/resume, not every pan/zoom sample. Playback uses current viewport with recorded translation/zoom; navigated framing/video export remains pending.

Native board JSON excludes recording. Separate JSON backup contains complete local recording; after validation, explicit confirmation can rebind recorded root board IDs into the current board's empty recording slot without altering live artwork. All stroke/layer identities within recorded snapshots retained. Import never replaces an existing recording. Discard is separately confirmed. Browser eviction/site clearing remains possible; backups recommended.

Preview is disposable and read-only to h.board; Stop/Close/error restores original view. Pause on blur/hidden/resize, explicit resume. Renderer errors surface through existing render status and cannot alter artwork; bounded state validation does not establish every imported board can render within backing limits. Existing rendering/performance limits remain.
