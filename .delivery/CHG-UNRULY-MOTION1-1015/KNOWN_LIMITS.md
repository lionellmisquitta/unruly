# Retained Motion Trace acceptance boundaries
- This build is translation paths and camera centre/zoom, not object rotation/scaling, a full animation timeline, motion video export or timelapse. Those were not claimed as delivered here.
-24cues,128points,250–30000ms,2MiBcue metadata within8MiBboard;32layer and existing backing/history bounds unchanged. No target-device FPS/palm/latency acceptance.
- Pixel-region cues retain a binary spatial mask and ordered original source IDs. Adding/deleting/replacing source strokes requires recapture. Editing existing stroke geometry with the same IDs reuses the same document-space mask against current artwork; it is not a persistent semantic subobject tracker.
- Region preview converts only a disposable copy; explicit commit rasterizes the affected layer, with one Undo restoring original vectors. After such a commit, recapture stale region/object cues or Undo before replay.
- Same selected-region target can repeat in a sequence; mixed independent region/whole-object targets on the same layer can become unresolved after an earlier transient region conversion. This compatibility gap remains OPEN; playback rejects the whole compile atomically instead of dropping targets or moving whole artwork. Saved cues are retained and can be deleted/retargeted. Folder motion and region cues on separate layers remain the available composition routes. Do not mark all C09M acceptance complete solely from MOTION1's tested paths.
- Physical Surface/Xiaomi/Lenovo, pen/palm/long-session/performance and owner audience-clarity acceptance remain OPEN. Original full-roadmap requirements,including Drive/BYOK AI first-release intent,are unchanged.
