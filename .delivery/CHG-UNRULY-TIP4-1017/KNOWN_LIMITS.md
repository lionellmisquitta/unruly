# TIP4 bounds

Guides/symmetry apply to future Vector ink with Alpha lock off. Image tips retain shape, grain, random rotation/scatter, pressure and saved seed. Up to4 editable native strokes commit together in one Undo. Like existing ordinary-ink symmetry, live preview shows the source; reflected copies appear on release. Axis-centred image tips retain distinct mirrored orientations, which can overlap. Native ordinary-ink centre-axis deduplication is unchanged.

Optional native17 stroke tipReflection holds strict {parity,heading}. Parity reverses local lateral scatter/random orientation; fallback heading handles degenerate/single-point strokes and rotates with selection. Tip library stays v1 with existing v1/v2 tip payloads; no new library format. Copy/paste and native import promote/preserve metadata. Older readers rejectv17; keep an owned JSON backup before rollback.

Existing aggregate4096stamp/4194304sampled-mask-pixel admission applies across all symmetry copies; each copy also passes normal replay admission. Document/history capacities are unchanged. Overflow cancels the whole gesture; no subset is retained. First preview can be visible before release refuses a too-large set of copies. Hidden/locked targets and ancestor rules retain existing guards. Guide-enabled alpha-locked image tips explicitly refuse; choose Alpha lock off/clipped-layer shading or guides Off. Pixel paint/masks/smudge and broader alpha-lock guide compatibility remain OPEN.

No canvas engine, render facade, storage/history rewrite or capacity increase. Raw snapshot/selection rendering receives the existing drawTip path, now parity-aware; raster edits remain undoable and do not preserve editable tips.
