# HSL1 interaction baseline
Spatial canvas with familiar native modal inspector, reusing existing text/import patterns. Entry: Adjust colour on each layer/folder Actions menu. One target label; sliders plus visible numeric values; Hue(-180..180), Saturation/Lightness(-100..100), input black/white(0..255, black<white), gamma(.1..10), output black/white(0..255, black<=white).
Live preview remains unsaved and locks competing editing. Apply commits metadata once, Cancel/Escape restores exact artwork. Reset previews neutral/removal; no-op Apply adds no history. Locked/hidden targets blocked; group descendant locks conservatively block group edits. Invalid values retain last valid preview and show error; Apply refuses. Render/allocation errors disable Apply, Cancel remains reachable. Dialog explains adjusted groups isolate, reset restores pass-through; original vectors/text remain editable. Reference/paper excluded. Backdrop interactions do not paint. Responsive dialog scrolls within viewport; labelled controls, keyboard Escape/Enter with explicit buttons. Blur/background cancels preview; stale board identity refuses Apply.
Evidence sufficient for established Apply/Cancel editor pattern. Composition isolation is declared design choice to satisfy combined group-image requirement; user can evaluate concrete published preview. No novel UI redesign.
