# COMP1 bounded composition contract

Native v16 is required for folder opacity/blend or masks; older readers reject it. Keep an owned JSON backup before rollback. Existing folders without explicit composition and without enabled masks/nonneutral effects retain pass-through rendering. Setting opacity or blend explicitly isolates, even 100%/Normal. Reset group composition removes only the pair; enabled masks/effects still isolate.

Order: child output (own effects, mask, clipping, opacity, blend) → folder HSL/levels → curves → Gaussian blur → folder mask → folder opacity once → folder blend into parent. Nested folders repeat. A named-folder clipping source uses that folder's processed masked alpha multiplied by its own opacity. A named nested-child source retains existing node-local alpha semantics: ancestor masks/effects/opacity are applied when the containing folder is composited, not silently baked into the child's external matte. Choose the containing folder for combined output. Group blend changes colour composition, not its source alpha matte.

Masks remain in document coordinates while content is transformed. Edit folder mask uses an editable descendant as the input anchor; empty folders cannot paint a mask. Changing active layer exits that edit mode. Hidden/locked ancestry or locked descendants reject group edits. Ungroup refuses saved masks/effects/explicit composition until explicitly removed/reset, including a disabled mask whose saved pixels would otherwise be lost. There is no implicit flattening.

Existing sparse mask snapshot/work limits, 32-layer/8MiB native board capacity and 80MiB render backing budget remain. More isolated nested groups consume existing budget and can reduce render resolution or refuse work under existing limits. Group cache stores post-mask/pre-opacity output and uses conservative board/live invalidation. This is not a new tiled composition engine or evidence of target-device/long-session capacity.

Original paper/canvas picker and raw layer thumbnail/snapshot boundaries remain. This build does not complete all painting/composition, physical wet pigment, proprietary brush import, pattern deformation, guides/image-tip compatibility, remaining workflow/Motion compatibility, video, artwork export, Drive or BYOK. No knowledge graph update. Verification is same-session; physical pen/palm/latency and independent human/device acceptance remain open.
